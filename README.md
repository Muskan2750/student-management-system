# Student Management System

A web-based **Student Management System** developed as an academic project using **Laravel, PHP, MySQL, HTML, CSS, and JavaScript**.

## Project Overview

The Student Management System is designed to manage student information through a web-based application. It uses the **Laravel framework** with **MySQL** for database management.

## Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* Laravel
* MySQL
* XAMPP

## Project Features

* Student information management
* Add student information
* Update student information
* Student database integration
* Laravel-based web application
* MySQL database connectivity

## Project Structure

The project follows the Laravel framework structure:

* `app/` – Application logic, controllers, and models
* `database/` – Database migrations and seeders
* `resources/` – Views, CSS, and JavaScript
* `routes/` – Application routes
* `public/` – Public application files

## How to Run the Project

1. Install **XAMPP** and start Apache and MySQL.
2. Install **Composer**.
3. Clone or download this repository.
4. Open the project folder in the terminal.
5. Install PHP dependencies:

```bash
composer install
```

6. Create a `.env` file using `.env.example`.
7. Configure the MySQL database in the `.env` file.
8. Run the Laravel application.
